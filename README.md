## 🌟 Overview

The **Blender Biome Generator** bridges the gap between Blender and Houdini-style procedural workflows. Designed for environment artists, level designers, and world-builders, this toolset uses advanced **Geometry Nodes** to populate vast terrains with intelligent flora, organic pathways, and set-dressing props automatically.

## ✨ Planned Features

* 🎛️ **Unified Parameter Panel:** Control entire biomes from a single, clean modifier stack.
* 🌿 **Smart Flora Scattering:** Multi-layer distribution with density maps, slope constraints, and collision exclusion.
* 🛤️ **Spline Paths & Roads:** Automatically carve terrain, clear vegetation, and edge-blend props along curves.
* 🪨 **Parent-Child Prop Spawning:** Cluster rocks, debris, and moss naturally around hero assets.
* ⚡ **Performance Optimized:** Built for high-density instancing and smooth viewport playback.

## 🛠️ Requirements

* **Blender 4.2 LTS** or newer (leveraging modern Geometry Nodes features).

## 🚀 Getting Started (Early Access / Source)

1. Clone or download this repository.
2. Open Blender and append or link the `BiomeGenerator_Core.blend` file into your project *(Coming Soon)*.
3. Assign the geometry node modifier to your base terrain mesh and start tweaking parameters!
